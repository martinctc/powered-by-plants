# Images Folder

Store your website images here.

## Structure

- `blog/` - Blog post images
- Root folder - General site images (logos, icons, etc.)

## Naming Convention

For blog images, use descriptive names:
- `2026-02-02-veganuary-dauns.jpg`
- `2026-02-02-veganuary-unity-diner.jpg`
- `recipe-mango-tofu-pudding.jpg`

Keep filenames lowercase with hyphens for spaces.
